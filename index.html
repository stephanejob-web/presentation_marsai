Choix technique

Pourquoi TypeScript · pas JavaScript ?

TypeScript impose un contrat de code partagé entre 6 développeurs — les erreurs sont détectées à la compilation, jamais en production.

❌ JavaScript — bug silencieux
function scoreFilm(film, note) { return film.titre + " : " + note.valeur } scoreFilm({ title: "..." }, 8) // → undefined au runtime 😬
✅ TypeScript — erreur immédiate
function scoreFilm(film: Film, note: Note): string { return `${film.titre} : ${note.valeur}/10` } scoreFilm({ title: "..." }, 8) // ✖ Erreur : title ≠ titre · 8 ≠ Note
